⚙️ Commands

🎲 Gambling
🎲 !gamble
!gamble <amount | all>
Double your points or lose them.
Example
!gamble 12345
!gamble all
🎰 !gambleslots
!gambleslots <amount | all>
Slot machine with bonus payouts.
Example
!gambleslots 500
!gambleslots all
🧪 Misc
📏 !pp
!pp
Measure your totally real size.
⚡ Actions
🩴 !chancla
!chancla <@user> | !chancla
Throw a chancla at a specific user or a random chatter.
Example
!chancla @user
!chancla
👑 Power
👑 !king
!king
Claim the throne (1 hour). Allows you to use the !tax command.
Example
Retry Cooldown: 5s
King Cooldown: 1hr
⚔️ !mutiny
!mutiny
Multiple chatters must also use this command at the same time to dethrone the king.
💰 !tax
!tax <@user> | !tax all
Tax the kingdom for 10% (everyone) or target a single user for 40%.
Example
!tax @user
!tax all
Cooldown: 1m
